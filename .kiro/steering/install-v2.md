# AWSops v2 Guided Install / 안내식 설치

Follow the single-source workflow below from Step 0 (scenario selection: fresh install / v1→v2 migration / remove-v1-then-reinstall). Show summaries and get the user's confirmation before every state-changing step (apply, deploy, backfill, cutover). The interactive TUI (`make configure`) must be run by the user in their own terminal.

시나리오 선택(신규 설치 / v1→v2 마이그레이션 / v1 제거 후 신규 설치)부터 아래 단일 소스 워크플로우를 순서대로 따른다. 상태를 바꾸는 단계는 실행 전 요약을 보여주고 사용자 확인을 받는다.
